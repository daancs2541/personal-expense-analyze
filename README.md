# Personal Expense Analyzer

A simple expense analysis program built with Python.

## Features

- Calculate total expenses.
- Calculate average expenses.
- Identify the highest and lowest expenses.
- Count expenses above 100 EUR.
- Handle empty expense lists.

## How to Run

1. Make sure Python 3 is installed.
2. Download `expense_analyzer.py`.
3. Run the file using Python.

## About

This is my first independent Python learning project. It focuses on basic Python concepts, including lists, loops, conditions, and built-in functions.
